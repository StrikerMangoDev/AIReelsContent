# Brand font assets

Plus Jakarta Sans (weights 400–800) and Source Sans 3 (400–700), normal variable WOFF2 Latin subsets. Retrieved 8 November 2026 from the Google Fonts CSS API with a modern-browser user agent. Other scripts use the declared system fallback; language-specific font subsets should be added when their typography is reviewed.

Upstream projects:
- https://github.com/tokotype/PlusJakartaSans
- https://github.com/adobe-fonts/source-sans

The corresponding SIL Open Font License notices are included alongside each font. These assets are served locally; the application no longer needs a Google Fonts stylesheet request for its brand typography.

On 9 November 2026 the same licensed WOFF2 files were decompressed locally to TTF with fontTools for the server SVG-to-PNG renderer. No font substitution or new upstream asset was introduced. The TTF derivatives retain the corresponding OFL notices in this directory.
