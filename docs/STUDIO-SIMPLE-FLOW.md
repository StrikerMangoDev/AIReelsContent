# Content Studio: simple local workflow

The user's October 28 update replaces the mandatory separate-reviewer workflow in older v1.3 plans for Content Studio.

1. Open a topic or saved draft.
2. Choose platforms and outputs on the same page. Carousel selection includes its required script automatically. Generate only after confirming the scope.
3. Edit the saved content beside the Instagram post/carousel preview. On mobile, switch between editing and preview. Save changes before downloading.
4. Click **Download content**. The server rechecks citations, output completeness, source-library eligibility and revision, records the authenticated creator's decision, and returns the current approved export. No reviewer assignment or separate approval screen is required.

Sources, version history and production tools remain available on the same workspace. Previous independent-review records and links are retained as historical/optional functionality; a creator confirmation never claims an independent human review occurred.

Edits or changed evidence invalidate ready status. Unauthorized access, stale revisions, unresolved citation problems, and concurrent changes cannot produce a download. Shared-workspace confirmation requires an active owner/editor; reviewer-only accounts cannot confirm content. Planner readiness uses the same policy.

Automatic checks establish citation integrity, not factual truth. The creator remains responsible for claims, source limitations and reuse rights. Downloading does not publish or schedule a post.

This implementation is local only. It does not enable paid services, scheduling, or deployment.
